## 📖 Descrizione
**Payment component professionale** con animazioni realistiche.
- **Live sync** input → carta (numero, nome, CVV)
- **3D flip** fronte/retro
- **Validazione** Luhn + formato
- **Responsive** mobile/desktop
  
  <br>

**Obiettivo CV:** Frontend interattivo + JS DOM manipulation.

<br>

## 🛠 Tech Stack
- **HTML5:** Form + semantic
- **CSS3:** 3D transforms, glassmorphism
- **JavaScript:** Event listeners, input formatting
- **Responsive:** CSS Grid + media queries
  
  <br>

## 🎮 Interactive Features
✅ Digita numero → ** ** **** 1234 (live) <br>
✅ CVV → Flip automatico carta retro <br>

✅ Data scadenza → MM/YY formato <br>

✅ Shake errore validazione <br>
